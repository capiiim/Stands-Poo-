# PD6 - FILEY: pagos de reservaciones

Continuación de PD5 con la entidad Pago y CRUD de stands, editoriales, reservaciones y pagos mediante MVC, JDBC y SQLite.

### Enlace al video

[Ver video explicativo de la PD6](https://drive.google.com/drive/folders/1WUVff4EWschvKv0dBe83z03XKOY_HswG?usp=sharing)

## Ejecutar

Requiere JDK 17 o superior y Maven. Desde la carpeta PD6:

```bash
mvn compile exec:java
```

Se genera `filey_pd6.db` automáticamente. Main demuestra el CRUD de las cuatro entidades, consultas por mes y por editorial/reservación, saldos y excepciones. Al finalizar, elimina sus datos de ejemplo.
